# 소리 수집소 · Everyday Sound Sampler

컵도, 키보드도, 내 목소리도 악기로 만드는 작은 브라우저 음악 장난감입니다. 회원가입, 외부 음원, 유료 API, 빌드 도구 없이 작동합니다.

## 바로 놀기

1. **뽁 · 딱 · 보잉 · 바스락** 패드를 누르거나 키보드 **A / S / D / F**를 누르세요. 기본 소리 네 개는 앱 코드가 직접 만든 합성음이므로 마이크 권한 없이 시작할 수 있습니다.
2. **우리 집 밴드**의 네모를 켜고 **재생**을 누르세요. 4개 소리 × 16칸, 한 바퀴 4박자입니다. BPM은 50–180으로 바꿀 수 있습니다. **추천 비트**로 시작해도 됩니다.
3. 패드의 **소리 바꾸기**를 누른 뒤 **3초 녹음** 또는 **파일 가져오기**로 자기 소리를 넣으세요. 마이크는 녹음 버튼을 눌러야 요청합니다. 파일은 최대 8MB, 길이 12초까지이며 브라우저가 디코딩할 수 있는 오디오여야 합니다.
4. 시작과 끝을 조절해 쓸 부분만 남기고 **미리 듣기**로 확인하세요. **WAV 저장**은 선택한 패드의 잘라낸 소리 하나를 기기에 다운로드합니다. 비트 전체를 내보내거나 프로젝트를 저장하는 기능은 아닙니다.

마이크가 거부되거나 지원되지 않는 환경에서는 **파일 가져오기**를 사용하세요. 파일 형식 지원은 브라우저마다 다릅니다. 호환 문제가 있으면 짧은 WAV 파일로 변환해 가져오세요. 녹음하려면 HTTPS 또는 `localhost`에서 열고 브라우저의 마이크 권한을 허용해야 합니다. 개인 소리를 다른 사람과 공유할 때에는 관련자의 동의를 받아 주세요.

## 개인 정보와 저장

- 앱은 녹음, 가져온 파일, 비트를 **업로드하지 않습니다**. 외부 서비스, 분석 코드, 네트워크 API 호출이 없습니다.
- 소리와 패턴은 현재 탭의 메모리에만 있습니다. `localStorage`, IndexedDB, 쿠키 등으로 저장하지 않습니다.
- 새로고침하거나 탭을 닫으면 작업이 사라집니다. 사용자 소리가 있으면 브라우저의 종료 경고를 요청하지만, 모바일/강제 종료 등에서는 경고가 표시되지 않을 수 있습니다. 간직할 소리는 먼저 WAV로 저장해 주세요.
- 사용자가 넣은 소리를 교체하거나 기본 소리로 되돌릴 때 확인을 받습니다. 비트 비우기와 소리 초기화는 별도입니다.
- 녹음은 최대 3초이며, 종료/취소 시 마이크 트랙을 정리합니다. 탭이 숨겨지거나 페이지를 떠나면 재생과 녹음을 중단합니다. 뒤늦게 마이크 권한이 허용되어도 취소된 요청의 트랙은 즉시 중단합니다.

## 로컬 실행

Node.js가 없어도 정적 서버로 실행할 수 있습니다.

```sh
cd apps/sampler
python3 -m http.server 8080 --directory dist
```

브라우저에서 `http://localhost:8080`을 여세요. ES 모듈을 사용하므로 `file://`로 직접 열기보다 로컬 서버를 권장합니다. 최신 Web Audio 지원 브라우저가 필요하며 녹음은 MediaRecorder 지원도 필요합니다. 모바일에서는 기기의 무음 모드와 브라우저 오디오 설정도 확인하세요.

## 개발과 검증

```sh
npm run check
npm test
```

의존성 설치와 빌드 과정은 없습니다. `dist/` 자체가 배포 산출물입니다.

- `dist/index.html`, `dist/styles.css`: 한국어 UI와 반응형 스타일
- `dist/app.mjs`: 패드, 편집기, 키보드와 페이지 수명주기 연결
- `dist/audio.mjs`: 기본 합성음, Web Audio 재생, WAV 출력, 마이크 수명주기
- `dist/core.mjs`: 16-step 스케줄러와 순수 헬퍼
- `tests/`: Node 내장 테스트 러너와 모의 브라우저/오디오 객체를 사용하는 테스트

실제 사용자 마이크나 장치에는 접근하지 않았습니다. 실기기 녹음, 실제 브라우저 렌더링, 터치/오디오 출력은 검증하지 못했습니다. 자동 테스트는 로직, 코드/DOM 계약 및 모의 오디오·녹음 수명주기를 확인하며 실제 브라우저 QA를 대체하지 않습니다.

## 배포

정적 호스팅에는 `dist/`의 파일만 제공하면 됩니다. 개인 녹음이나 가져온 오디오는 프로젝트 디렉터리에 기록되지 않습니다. 외부 글꼴과 음원 파일은 포함하지 않습니다. HTTPS에서 마이크 기능을 제공할 수 있지만 임베드 정책이나 브라우저 권한에 따라 마이크 사용이 제한될 수 있습니다. 그런 경우 파일 가져오기는 계속 사용할 수 있습니다.
