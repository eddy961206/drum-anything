# Drum sample sources

These six recordings are from Virtuosity Drums by Versilian Studios and Karoryfer Samples, released under [CC0 1.0](https://github.com/sfzinstruments/virtuosity_drums/blob/9f04cf9a734527edfbb0a4eee1f674e45bbf71bc/LICENSE). They are stored locally; playing the pads makes no network request.

The five AAC files are the CC0 same-microphone adaptations in [Keyboardia](https://github.com/adewale/keyboardia/blob/869d3f5095084003e1251aa3ebf2eab8f65f62fe/app/public/instruments/LICENSE.md), pinned to commit `869d3f5095084003e1251aa3ebf2eab8f65f62fe`:

| Local file | Original file |
| --- | --- |
| `kick.m4a` | `acoustic-kick/source-0013.m4a` |
| `snare.m4a` | `acoustic-snare/source-0028.m4a` |
| `hat.m4a` | `acoustic-hihat-closed/source-0013.m4a` |
| `open-hat.m4a` | `acoustic-hihat-open/source-0010.m4a` |
| `crash.m4a` | `acoustic-crash/source-0009.m4a` |

`tom.flac` is [`Samples/mid/htom/mid_htom_center_vl12.flac`](https://github.com/sfzinstruments/virtuosity_drums/blob/9f04cf9a734527edfbb0a4eee1f674e45bbf71bc/Samples/mid/htom/mid_htom_center_vl12.flac) from the original CC0 repository. The files are unchanged; playback gain and short start offsets are applied by the app.
